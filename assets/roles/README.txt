Para usar tus iconos reales:
1. Reemplaza cada PNG en esta carpeta manteniendo el mismo nombre de archivo.
2. Reinicia el bot: actualizará los emojis del servidor automáticamente.

Regenerar placeholders de prueba:
  node scripts/generarPlaceholders.js

Configura GUILD_ID en .env para que el bot suba/sincronice los PNG como emojis del servidor.
